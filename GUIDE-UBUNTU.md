# Guide Ubuntu — FleetBook Next.js

Cette version utilise un seul conteneur Next.js (frontend + API) et PostgreSQL. **Ne pas suivre l'ancien guide Drive** : il suppose un fichier Drizzle et des commandes qui ont changé. Les instructions validées et le tunnel Windows sont dans [README.md](README.md). Les captures attendues : `npm run build`, `docker compose ps`, `/api/health`, le nombre d'utilisateurs/véhicules et une connexion aux comptes fictifs. Aucun service n'est publié hors de la boucle locale.
